# Politique de sécurité

Ce dépôt contient un site statique (HTML, CSS, JavaScript sans dépendance externe).

## Signaler une vulnérabilité
- Utilise de préférence **Security > Report a vulnerability** (signalement privé GitHub) de ce dépôt.
- Sinon, écris à **ennouaim159@gmail.com** avec « SECURITY » dans l'objet.
- Merci de ne pas publier la faille avant correction. Réponse sous 7 jours.

## Périmètre
Le site n'utilise ni cookie ni statistiques. Le formulaire de contact (optionnel) envoie le message via un script Google Apps Script vers la boîte de l'auteur, après un test anti-robot Cloudflare Turnstile chargé uniquement quand le visiteur commence à écrire. Aucun secret n'est stocké dans le dépôt.
